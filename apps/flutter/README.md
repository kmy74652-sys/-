# تطبيق إدارة الشاعري - Flutter

هذا مجلد تطبيق Flutter الجديد، ويعمل مؤقتًا بجانب تطبيق Expo/React Native الحالي إلى أن تكتمل عملية الترحيل والتحقق الوظيفي.

## الحالة الحالية

- Flutter stable 3.50.1 وDart 3.14.0.
- دعم أولي للعربية وRTL وMaterial 3.
- اعتماد `supabase_flutter` مضاف.
- اتصال Supabase الإنتاجي مضبوط افتراضيًا باستخدام نفس عنوان المشروع ومفتاح النشر العام المستخدمين في Expo، ويمكن تبديلهما عبر `dart-define`.
- مجلدات الميزات الأساسية جاهزة: الهوية، المهام، والتقارير.

## التشغيل

```bash
export PATH="$HOME/flutter/bin:$PATH"
flutter pub get
flutter run \
  --dart-define=SUPABASE_URL="https://your-project.supabase.co" \
  --dart-define=SUPABASE_ANON_KEY="your-anon-key"
```

مفتاح النشر العام ليس مفتاح خدمة سريًا، وتبقى الحماية معتمدة على Auth وRLS وRPC في Supabase. يمكن تمرير مشروع آخر وقت التشغيل دون تعديل المصدر.

## الهيكل

```text
lib/
  core/
    config/       إعدادات البيئة وSupabase
    routing/      التنقل المركزي
    theme/        الثيم والألوان RTL
  features/
    auth/         تسجيل الدخول والصلاحيات
    tasks/        المهام والتنفيذ والمراجعة
    reports/      النماذج وحالات التقارير
  shared/widgets/ المكونات المشتركة
  main.dart       نقطة التشغيل
```

تقرأ طبقة المهام ملف المستخدم عبر `mobile_my_profile`، ثم تقرأ `tasks` والفروع مع احترام صلاحيات `tasks.manage` و`tasks.review` و`tasks.execute`. لا تستخدم هذه المرحلة تحديثات مباشرة، وتبقى عمليات التغيير لاحقًا عبر RPC الآمنة الموجودة في قاعدة البيانات.

## المسارات الحالية

يستخدم التطبيق `go_router` مع غلاف موحد وشريط تنقل RTL:

- `/` — لوحة الرئيسية والملخص.
- `/tasks` — قائمة المهام والفلاتر وحالة الإسناد.
- `/reports` — التقارير مع حالات `draft`, `submitted`, `reviewed`, `approved`, و`returned`.
- `/more` — الحساب والإعدادات والمساعدة.

صفحة المهام مرتبطة الآن بقراءة البيانات الحقيقية مع حالات التحميل والخطأ والتحديث والبحث والفلاتر. ستتم إضافة عمليات التنفيذ والتقارير عبر RPC في المرحلة التالية.
