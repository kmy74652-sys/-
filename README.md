# برنامج الشاعري

هذا مستودع جديد ومستقل لنظام الإدارة والمتابعة والرقابة المؤسسية. لا يحتوي على بيانات من المشروع القديم ولا يتصل به.

## المرحلة الحالية

النواة الحالية تشمل العملاء والحسابات والتحصيل، والكتالوج والموردين، والمبيعات والمشتريات والمرتجعات والجرد وحركات المخزون والتقارير. أضيف تطبيق Android Expo/React Native داخل `apps/mobile` مع إعداد EAS لإخراج APK. قاعدة Supabase تحتوي مؤسسة وفرعًا وموظفين، ولا تُنشأ بيانات تجريبية تلقائيًا. يبقى الاختبار على جهاز فعلي والمزامنة دون اتصال واختبار التشغيل ببيانات المؤسسة الفعلية قبل الإصدار الإنتاجي النهائي.

## التشغيل المحلي

1. انسخ `.env.example` إلى بيئة آمنة أو استخدم أسرار المشروع المحمية.
2. نفذ `pnpm install`.
3. تحقق من المخطط مبدئيًا عبر `pnpm schema:verify`.
4. بعد توفير مشروع Supabase مستقل، نفذ المهاجرات من خلال Supabase CLI أو SQL migration pipeline.
5. شغّل اللوحة وAPI عبر `pnpm dev`.

لا تضع `SUPABASE_SERVICE_ROLE_KEY` في كود المتصفح أو Git. لا تنفذ أي migration على قاعدة بيانات التدريب أو المشروع القديم.
